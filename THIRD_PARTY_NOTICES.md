**River Server** (scripts, the RiverLife mod and server plugin, RiverAdmin and the *riverpack* River Highway fixes) is
original work by Chiarello.

It relies on, and its release page offers as optional downloads, work by other people. All rights to those files stay
with their authors; they are redistributed unchanged, as optional assets of the release, so a server can hand them to
its players. If you are one of the authors and want a file removed or credited differently, open an issue and it will
be done promptly.

The *riverpack* fixes (`riverpack.zip`) contain original code plus two JSON definition files derived from the West Coast
USA level that ships with BeamNG.drive (forest item and material definitions), so River Highway can use the game's own
models and textures already installed with the game (paths into `/levels/west_coast_usa` and `/assets`). No models or
textures are copied.

RiverOS's look is inspired by the computer of "Better Career" 0.5.2; no Better Career code or images are included.
