original work by Chiarello.

It relies on, and its release page offers as optional downloads, work by other people, redistributed with their
authors' permission so a server can hand them to its players. All rights to those files stay with their authors. If

promptly.

The *riverpack* fixes inside the map zip: material files repointed at the textures that moved in BeamNG.drive 0.39,
delivery facility data, a few level objects, the `riverPackCompat` script (original code), and two JSON definition files
derived from the West Coast USA level that ships with BeamNG.drive (forest item and material definitions), so River
Highway can use the game's own models and textures already installed with the game (paths into `/levels/west_coast_usa`,
`/levels/GridMap` and `/assets`). No game models or textures are copied. The zip carries a
`README_RiverHighway_fixed.txt` with the full credits and list of fixes.

RiverOS's look is inspired by the computer of "Better Career" 0.5.2; no Better Career code or images are included.
